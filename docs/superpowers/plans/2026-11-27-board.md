# Board — implementation plan (1.8.0)

Spec: `docs/superpowers/specs/2026-11-27-board-design.md`. Each task ends green
(`npm test`, `npm run typecheck`); TDD tasks write the failing test first.

## A. Backend core (Python, stdlib only) — `dashboard/boardkit/`

1. **ids + paths** (TDD): `valid_bid`, `valid_aid`, `new_bid`, `item_id(n)` base36,
   `BoardStore(root)` resolving `<bid>.json/.log.jsonl/.lock`, refusing anything outside root.
2. **op engine** (TDD): `apply_batch(doc, ops, by)` → `(doc, inv, ids)`; add/set/del/board,
   `$refs`, columns (`in`, `kids`), cascade deletes of connectors and column kids, field
   sanitising per kind, limits, all-or-nothing on error. Inverse round-trip test.
3. **store** (TDD): create/list/load/delete(trash), `commit(bid, ops, by, note)` under `flock`,
   atomic write (tmp + `os.replace`), log append, compaction to 2 000 entries,
   `since(bid, seq)` → `{seq}` / entries / full doc, `undo(bid, s)`, presence update.
4. **outline + diff** (TDD): `outline(doc)` compact lines, `changes_since(bid, seen, exclude_by)`
   summary for the hook (≤ 1 500 chars), `mark_seen`.
5. **assets** (TDD): base64 upload caps, magic sniff (png/jpg/gif/webp/ico, html for embeds),
   content-addressed store, read back.
6. **URL classification** (TDD): video providers, direct video/image files, generic.
7. **SSRF-safe fetcher** (TDD): address policy, pinned connection, manual redirects ≤ 3,
   deadline, caps, content-type gates. Resolver and opener injectable for tests.
8. **link preview** (TDD): OG/Twitter/title/description/icon parser, oEmbed discovery + known
   provider endpoints, thumbnail/og:image/favicon into assets, 7-day cache, failure shape.
9. **render** (Pillow optional): `render_png(doc, region)`.

## B. Backend surfaces

10. **REST routes** in `dashboard/plugin_api.py` (§9 of the spec), loading boardkit by path;
    tests through the route functions (no FastAPI needed).
11. **Agent half** in `__init__.py`: tools `board_read`, `board_apply`, `board_render`; hook
    `pre_llm_call`; session linking (`[board:<bid>]` marker, first read/write); `plugin.yaml`
    `provides_tools` / `provides_hooks`. Tests call the handlers directly with a temp
    `HERMES_HOME`.

## C. Frontend

12. **Remove Agent widget** (TDD for migration): delete files, registry entry, theater, i18n keys;
    `parseLayout` drops unknown ids.
13. **TS mirror** (TDD): `src/board/model.ts` (types + `applyOps`), `urlKind.ts`, `geometry.ts`
    (RDP simplify, elbow routing, ports, bounds), shared fixtures with Python where possible.
14. **Fonts**: subset 4 families → `src/board/fonts.css` with data URLs; licences in `fonts/`.
15. **Board page**: `BoardPage.tsx` (viewport pan/zoom, culling, selection with crop marks,
    context bar, marquee, drag, resize, keyboard), item renderers (card, todo, column, link,
    video, image, embed, board, frame, box, text, draw), connectors SVG, freehand tool, paste/drop
    (images, URLs), top title line, status line + `hermes ›` prompt, map, Hermes log, Hermes
    cursor driven by the op stream, undo/redo stack, polling hook.
16. **Boards index** page + Home **Board widget** (live dot preview, picker on hover).
17. **Host wiring**: Desktop routes `/boards`, sidebar "Boards", palette; session actions
    (`openSession`, `newChat` + composer draft, `session.resume`/`session.create` +
    `prompt.submit` through `host.request`); `SandboxedFrame` feature-detected; web dashboard
    hash routing and fallbacks.
18. **i18n** en + es for every new string (key parity test).
